# Agent Workflow Rules
Before writing code for any new feature or complex UI component, you MUST ask me 2-3 clarifying questions about how it should look or behave, and wait for my response.
Always refer back to `requirements.md` and `design.md` before implementing tasks from `tasks.md`.
Create at least 5 test cases for each feature implemented if applicable, making sure to include edge cases. Run the test cases yourself and based on the output, report back to me the minimal fix proposed to resolve any issue or that the test was successful. 
Ask me for specifics regarding UI changes or how a specific part of the website should look before implementing.
